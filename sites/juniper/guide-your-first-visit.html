Juniper · guide one

Twelve questions for a first visit

Before you book

  1. Ask whether a first visit can start as a conversation only.
  2. Ask for a chaperone, or say who you’re bringing.
  3. Say if you’d prefer a clinician of a particular gender.
  4. Ask about step-free access or an interpreter.

In the room

  1. Start with the question you most want answered.
  2. Ask what any examination would involve, and why, before it starts.
  3. Ask whether a smaller speculum or a different position is possible.
  4. Say if a past examination was difficult. You don’t have to explain why.
  5. Ask what each test is for.

Before you leave

  1. Ask how you’ll get results, and how long it takes.
  2. Ask who to contact if something changes.
  3. Ask whether you need to book the next step yourself.
